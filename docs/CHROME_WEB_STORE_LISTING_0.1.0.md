# Chrome Web Store Listing - 0.1.0

Doc Progress Tracker helps you save and restore your reading progress on developer documentation and long documentation pages.

It works best on selected supported documentation sites, including React Learn, Playwright Docs, and OpenAI Codex Docs.

The extension also includes experimental detection for common documentation frameworks such as Docusaurus, Fumadocs, Material for MkDocs, Nextra, Starlight, and VitePress. Because many documentation sites customize their layout, framework-based detection may not work perfectly on every site.

Features:
- Save reading progress on supported documentation pages
- Restore your previous reading position when you return
- Detect long documentation-style pages
- Designed for multi-column developer documentation layouts
- Store reading progress locally in your browser

Privacy:
Your reading progress is stored locally in your browser. The extension uses page URL, page title, and reading position to restore your progress. It does not upload page content to a server, sell your data, or use your reading data for advertising.

This is an early version. More supported sites and better framework detection will be added over time.
