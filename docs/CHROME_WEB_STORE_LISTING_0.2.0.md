# Chrome Web Store Listing - 0.2.0

Doc Progress Tracker helps you save, view, pause, resume, and restore your reading progress on developer documentation and long documentation pages.

It works best on selected supported documentation sites, including React Learn, React Reference, Playwright Docs, and OpenAI Codex Docs.

The extension also includes experimental detection for common documentation frameworks such as Docusaurus, Fumadocs, Material for MkDocs, Nextra, Retype, Starlight, and VitePress. Because many documentation sites customize their layout, framework-based detection may not work perfectly on every site.

Features:
- Create a local index for supported documentation sites
- Save reading progress on supported documentation pages
- Restore your previous reading position when you return
- Show total documentation progress in the page sidebar
- Show per-page progress badges in supported documentation navigation
- Show an optional right-side reading map for viewed sections
- Pause or resume progress recording for an individual page
- Turn reading progress on or off for an indexed site
- Delete progress for a single page, a site, or all indexed sites
- Resume an interrupted indexing run when the page list still matches
- Export and import local indexes, with an option to include reading progress
- Choose from 12 interface languages for extension pages and injected reading UI
- Store indexes, settings, and reading progress locally in your browser

Privacy:
Your reading progress is stored locally in your browser. The extension uses page URL, page title, page height, reading ranges, and reading position to calculate and restore your progress. It does not upload page content to a server, sell your data, or use your reading data for advertising.

This is still an early version. More supported sites, better framework detection, and improved documentation-site compatibility will be added over time.
